# 贯穿案例

不要每一章换 Demo。让同一个项目不断升级，才能看见 Harness 能力增长带来的真实差异。

课程围绕 **6 个长期贯穿案例** 展开，从 Hello World 一路做到 Repeated Task：

## Case 1 · Hello World

```text
创建 hello.ts
```

适合：Agent Loop、write、bash。

## Case 2 · Bug Fix

```text
修复 failing test
```

适合：read、edit、bash。

## Case 3 · Feature Implementation

```text
实现 TODO feature
```

适合：multi-step、session、context。

## Case 4 · Large Codebase Analysis

```text
分析一个中大型仓库
```

适合：context compaction、RLM、context as variable。

## Case 5 · Multi-module Task

```text
同时分析前端、后端和数据库
```

适合：recursive agents、parallel agents。

## Case 6 · Repeated Task

```text
连续做 10 次「分析 npm package」
```

适合：memory、skill creator、continual harness、evaluation。

读者最后可以直观看到：

```text
第一次任务：14 steps
第十次：    5 steps
```

这就是“自我演进”最好的展示。
